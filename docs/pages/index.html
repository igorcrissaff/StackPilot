Gerenciamento de Containers

Liste, inicie, pare, reinicie, remova e acompanhe logs diretamente via /var/run/docker.sock com filtro instantâneo.

Docker Hub & Criação de Stacks

Pesquise imagens no Docker Hub, escolha tags com cache local em SQLite, gere um compose.yaml inicial e faça deploy direto da interface.

Editor Docker Compose

Edite arquivos compose.yaml e variáveis .env com validação de sintaxe YAML e deploy imediato.

Rotas HTTP com Traefik

Crie e remova subdomínios locais (*.home.arpa) via arquivos YAML dinâmicos do Traefik com validação automática.

Arquitetura enxuta e fácil de auditar

Sem pipelines de build complexos ou dezenas de dependências Node.js. O StackPilot usa FastAPI, Jinja2, HTMX e Tailwind CSS para entregar uma interface reativa com consumo mínimo de memória.

  • Backend assíncrono em FastAPI + Pydantic Settings
  • Cache local em SQLite para buscas do Docker Hub
  • Autenticação simples de administrador via cookie assinado
app/ 
├── main.py          # FastAPI app & dashboard
├── auth.py          # Sessão cookie assinada
├── routers/         # Rotas HTMX (containers, docker, routes)
├── services/        # Docker, Docker Hub, Compose & Traefik
└── templates/       # Jinja2 + HTMX + Tailwind

Via Docker Compose

Recomendado 
git clone https://github.com/igorcrissaff/StackPilot.git
cd StackPilot
cp .env.example .env
docker compose up -d

Acesse http://localhost:8000 após iniciar os containers.
